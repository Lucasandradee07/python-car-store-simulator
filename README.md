#### Car Dealership Management System (Python)

#### Objetivo (Objective)

Este projeto consiste em um sistema desenvolvido em Python (com mais de 400 linhas de código) que simula o funcionamento e o gerenciamento de uma loja de carros. O foco principal da aplicação é a estruturação de regras de negócio utilizando funções modulares e controle de fluxo via terminal, com uma interface gráfica (GUI) em **Tkinter** atualmente em fase de desenvolvimento. 

#### Funcionalidades Principais

* **Versão Terminal (Concluída):** Cadastro, listagem de veículos disponíveis no estoque, consulta de modelos e simulação de operações de venda.
* **Estrutura Modular:** Código organizado em funções para facilitar a manutenção e o crescimento do sistema.
* **Interface Gráfica (Em andamento):** Protótipo inicial sendo construído com a biblioteca **Tkinter**.
